# Font rights gate and batch HarfBuzz regression

## 1. Exact source evidence

The published corpus contains 52 exact font files across 20 Google Fonts families. The evidence pipeline:
- verifies each exact font SHA-256 and pinned Google Fonts source revision;
- snapshots all 20 family-level license files from immutable revisions;
- checks the SIL OFL 1.1 marker and selected required clauses;
- preserves copyright headers, possible Reserved Font Names (RFNs), license URLs, and license snapshot hashes.

The latest pinned evidence artifact is `pinned-font-license-evidence`. Its audit passed for all 20 license snapshots with zero retrieval/integrity errors.

## 2. Conditional OFL AI-training permission

The official SIL OFL FAQ version 1.1-update8 (November 2026) addresses AI font generation:
- Q1.25 says a font generated by an AI/ML system using OFL font source data is a derivative font and cannot be released under a different license without explicit permission from the corresponding authors.
- Q3.9 confirms AI-based font design tools may modify OFL sources, but resulting released font software must remain under OFL and retain the normal derivative-font notices and acknowledgements.

Official source: https://openfontlicense.org/ofl-faq/

Project decision: the 52 hash-pinned SIL OFL 1.1 source files may be used as conditional training inputs **only if every generated font software output based on them is released under SIL OFL 1.1**, applicable copyright notices and acknowledgements are preserved, and generated fonts do not use any recorded Reserved Font Name without written permission.

This is documented in `docs/OFL_AI_TRAINING_POLICY.md`.

## 3. Build and validate the per-file manifest

The new script `scripts/build_ofl_training_rights_manifest.py` combines:
- the exact per-file candidate queue;
- the pinned license evidence audit;
- the official OFL FAQ policy and output conditions.

It creates `data/manifests/font_rights.json` with one record per exact font file. The manifest stores each SHA-256, pinned license URL, source URL, copyright notices, RFNs, evidence references, and conditional approval notes.

The CI workflow `.github/workflows/build-ofl-rights-manifest.yml` downloads the published corpus, rebuilds the candidate queue, snapshots the exact license texts, generates the conditional manifest, and verifies every file path and SHA-256 against the actual font binaries. Its artifact is named `conditional-ofl-font-rights-manifest`.

Run the same steps locally:

```bash
python scripts/build_font_rights_candidates.py --fonts-jsonl data/raw_fonts/fonts.jsonl --font-root data/raw_fonts --output reports/font_rights_evidence_candidates.json
python scripts/audit_google_fonts_licenses.py --candidates reports/font_rights_evidence_candidates.json --output-dir reports/font_license_evidence
python scripts/build_ofl_training_rights_manifest.py --candidates reports/font_rights_evidence_candidates.json --license-audit reports/font_license_evidence/license_evidence_audit.json --output data/manifests/font_rights.json
python scripts/validate_font_rights_manifest.py --manifest data/manifests/font_rights.json --font-root data/raw_fonts
```

The validator rejects unapproved entries, duplicate paths, malformed hashes, unsafe paths, missing files, and SHA-256 mismatches.

## 4. Batch shaping regression

After the manifest validates, run:

```bash
python scripts/run_batch_shaping_regression.py --manifest data/manifests/font_rights.json --font-root data/raw_fonts --output-dir reports/local/shaping
```

The runner stops before shaping if any manifest entry fails the rights/hash gate. It writes one HarfBuzz report per font plus `batch_summary.json`.

## 5. Important scope and noncommercial limitation

- SIL OFL 1.1 is **not** a NonCommercial license. This project can distribute its own model and generated fonts for free, but OFL does not prevent downstream commercial use of generated fonts, subject to OFL terms. It does prevent selling the font software by itself.
- If the project requires downstream users to be prohibited from commercial use, OFL is not suitable; explicit written permission to use a different license is needed.
- The manifest does not decide the license of model weights. Keep model-weight licensing separate.
- Arabeyes GPL+Font Exception, CC BY/CC BY-NC leads, and other external candidates are not covered by this OFL manifest.
- This is a project-level policy mapping of official SIL guidance, not a court determination or individualized legal advice.
- Passing the rights/hash gate does not establish visual quality, Arabic spelling correctness, readability, calligraphic quality, or human annotation accuracy. The overall training-readiness report keeps these separate gates independent.
